# Spirit Stones: Remastered
Puzzle-RPG "connetti le gemme": 25 mondi a difficoltà crescente, eroi con sprite
evolutivi (Grado 1/2/3), negozio con compra/vendita, ricompense a rarità a fine
stage, tabellone a nido d'ape. Solo browser, nessun build.

## Avvio
Apri `index.html` (funziona da `file://`) oppure `npm run dev`.

## Moduli (js/): persistence · data (mondi/oggetti) · dom (impostazioni) · assets
(immagini) · ui (negozio compra/vendi) · board (spada full-line) · battle (cascata,
ricompense) · main.

## Pubblicare su GitHub
`git init && git add . && git commit -m "init" && git branch -M main`
`git remote add origin <URL> && git push -u origin main` → Pages: branch main, root.

Immagini incorporate in `js/assets.js`. Grafiche originali dell'autore; nessun asset di terze parti.
